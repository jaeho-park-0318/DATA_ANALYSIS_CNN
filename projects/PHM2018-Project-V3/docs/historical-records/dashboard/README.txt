# 로컬 구간 탐색 대시보드

V3 폴더에서 PowerShell로 실행합니다.

```powershell
& 'C:\Users\fl27\anaconda3\envs\phm2018\python.exe' 'dashboard/app.py' --port 8765
```

브라우저에서 [로컬 대시보드](http://127.0.0.1:8765)를 엽니다. 서버를 종료하려면 실행한 터미널에서 Ctrl+C를 누릅니다. 이 작업의 미리보기 서버는 검증 후 종료될 수 있으므로 위 명령으로 다시 실행할 수 있습니다.

## 탐색 순서

1. 전체 장비 표를 장비 ID로 필터링하거나 열 제목으로 정렬합니다.
2. 장비와 고장 유형을 고르고 이벤트를 선택합니다.
3. H, 특징 A/B/C, 라벨 정책을 선택합니다.
4. ‘선택 구간 확인’을 누릅니다. 직접 시작/종료 raw를 입력해도 됩니다.
5. 센서, TTF 상태, 특징 가용성, 유형별/통합 라벨, 제외 사유를 함께 확인합니다.
6. ‘검토 사례’에서 긴 공백·충돌·TTF Null·이력 부족 등 대표 사례를 엽니다.
7. ‘선택적 로딩 내역’에서 파일/row group/반환 행 수를 확인합니다.

차트는 마우스로 확대·이동할 수 있습니다. 장비 타임라인과 관측 밀도에서 시각을 클릭하면 주변 구간을 엽니다. 확대 범위는 입력 칸으로 지정할 수도 있습니다. 상세 조회 최대 폭은20,000 raw이며 이동 통계용 과거900 raw를 서버에서 추가 조회합니다.

## 데이터와 해석

- 원본 데이터와 계산은 로컬에만 있습니다. 서버는127.0.0.1에만 바인딩합니다.
- 브라우저에는 전체 원본을 보내지 않습니다. 전체 장비 집계, 선택 장비의 구간 요약, 요청한 시각의 센서만 전달합니다.
- 원본 센서(float64)와 동시각 평균을 구분합니다. 공백>12 raw에서는 선을 연결하지 않습니다. 0은 실제0으로 보존하고 결측은 빈칸으로 표시합니다.
- L=60이며60 경계는 양성에 포함합니다. 어느 유형이든0≤TTF<60이면 통합 라벨에서도 제외가 우선합니다.
- 제한 연구용/완전 이력 가정의 음성은 검증된 정상 운전이 아닙니다. 상세 규칙은 [전처리 명세](../reports/00_preprocessing_spec.md)를 봅니다.
- 고장 이후 표시는 참고입니다. 단위·정비 종료·로그 완전성은 미확정이며 모델은 학습하지 않았습니다.

## 의존성과 오프라인 실행

기존 phm2018의 pandas/numpy/pyarrow를 사용합니다. Flask나 Streamlit 설치는 필요하지 않습니다. Plotly.js3.1.0은 공식 CDN에서 최초1회 받아 `assets/plotly-3.1.0.min.js`에 저장했습니다. 실행 중 외부 CDN에 접속하지 않습니다.

자산을 새 환경에서 복원할 때만 다음을 실행합니다. 센서 데이터는 전송하지 않습니다.

```powershell
Invoke-WebRequest -Uri 'https://cdn.plot.ly/plotly-3.1.0.min.js' -OutFile 'dashboard/assets/plotly-3.1.0.min.js'
```

캐시와 CSV/Parquet를 다시 만든 뒤 실행 중인 서버는 재시작해야 합니다. 포트가 사용 중이면 `--port 8766`을 사용합니다.
