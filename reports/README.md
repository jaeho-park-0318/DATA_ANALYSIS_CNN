The comparison slides were prepared before the GitHub notebook review. Statements in those slides that the historical notebook was unavailable describe the evidence available at that time. The current Markdown documents reflect this additional evidence. Earlier model checkpoints and per-wafer predictions are still unavailable, and the CNN was not rerun.

Process-pattern explanations are diagnostic hypotheses rather than proof of causation. Use process logs, inspection, metrology, and controlled experiments to confirm a suspected cause. See the presentation's figure captions and speaker notes for source attribution and study-specific limits.
